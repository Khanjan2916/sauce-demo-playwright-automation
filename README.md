# Sauce Demo - Playwright Automation

## Project Overview
This project contains automated tests for the Sauce Demo website using Playwright and JavaScript.

Website: https://www.saucedemo.com/

## Tools & Technologies
- Playwright
- JavaScript
- Node.js
- Git
- GitHub

## Test Coverage
- Login functionality
- Product page testing
- Shopping cart testing
- Checkout functionality
- Purchase flow
- Logout functionality
- API testing
- SQL database practice

## Installation

Clone the repository:

git clone https://github.com/Khanjan2916/sauce-demo-playwright-automation.git

Go to the project folder:

cd sauce-demo-playwright-automation

Install dependencies:

npm install

Install Playwright browsers:

npx playwright install

## Run Tests

Run all tests:

npx playwright test

View the HTML test report:

npx playwright show-report

## Project Structure

- tests/ — UI automation tests
- api-tests/ — API-related tests
- database-tests/ — SQL practice and database scripts
- playwright.config.js — Playwright configuration
